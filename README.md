# 온결 피부과 랜딩페이지

온결 피부과 콘셉트의 한국어 반응형 정적 랜딩페이지입니다. 페이지는 단일 HTML 파일로 구성되어 별도 패키지 설치나 빌드 과정 없이 실행할 수 있습니다.

## 실행 방법

`dist/index.html`을 브라우저에서 열어 확인합니다. 별도 패키지 설치나 빌드는 필요하지 않습니다.

## 구성

- `dist/index.html`: 랜딩페이지 본문, 스타일, 메뉴와 FAQ 인터랙션
- `.openai/hosting.json`: 사이트 프로젝트 및 정적 파일 디렉터리 설정

## 운영 정보 수정

실제 병원 정보가 준비되면 `dist/index.html`에서 병원명, 진료 항목, 진료 시간, 전화번호, 주소와 예약 링크를 확인해 수정합니다. 현재 운영 정보 영역에는 교체용 안내 문구가 들어 있습니다.

진료 항목과 안내 문구는 실제 의료진의 진료 범위와 병원 정보에 맞춰 게시 전에 확인해야 합니다.
